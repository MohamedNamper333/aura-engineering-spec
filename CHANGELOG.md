## Change Categories

For future updates, changes should be grouped using the following categories:

## Versioning Notes

- Major updates indicate significant architectural or governance changes.
- Minor updates indicate new documents or expanded guidance.
- Patch updates indicate clarifications, fixes, or formatting improvements.
